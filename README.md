## 📂 Estrutura

O código da aplicação está atualmente na pasta `chat bot/`, contendo a aplicação principal, serviços, integrações, templates e dependências.

## ▶️ Executando o projeto

```bash
git clone https://github.com/Lehguto12/Chat-Bot-IA.git
cd Chat-Bot-IA/"chat bot"
pip install -r requirements.txt
python app.py
```

Antes de executar, configure as variáveis de ambiente exigidas pelas integrações utilizadas.
